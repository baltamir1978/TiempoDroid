# TiempoDroid

El tiempo de AEMET (e IPMA en Portugal), la estación Netatmo de casa, sol y luna, mareas y cuatro widgets.

Versión para Android de [Tiempo ES (AppPersonal)](https://github.com/baltamir1978/AEMET-Netatmo-ios), la app de iOS. No es un port:
se escribe desde cero, con la app original como especificación.

**Estado: sin empezar** (21-oct-2026).

## Pila

Kotlin + Jetpack Compose, para **Android 12 o posterior**.
